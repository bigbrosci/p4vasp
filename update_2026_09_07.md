# p4vasp fixes — 2026-09-07

This update records the structure-viewer and Measure-interface fixes completed during this session.

## Fixed issues

- The structure viewer now opens with a white background and black unit-cell/supercell outlines, improving the visibility of both atoms and cell boundaries.
- Atomic element colors in `atomtypes.xml` were updated to the requested Jmol-style color values.
- The Structure Window Control toolbar now has a Side button.  Top and Side views redraw immediately after they are selected.
- Sphere-size and arrow-size sliders now use GTK3-compatible Adjustment APIs.  Changing the sphere-size slider updates the displayed atomic radii.
- The Measure applet now handles its startup phase safely when no active structure has been assigned yet, avoiding a measurement-table initialization error.
- The Z-matrix radio button is selected by default when the Measure applet opens.
- Fixed the Measure table layout for selections of three or four atoms.  The table had all rows internally, but GTK3 allocated space for only its header and two rows, hiding the angle and dihedral rows.  The table is now packed to fill the available vertical space.

## Verification

- Modified Python files compile successfully.
- Bundled test suite: **51 tests passed**.
- GTK regression check confirmed:
  - A three-atom selection shows 3 rows and an angle in the third row.
  - A four-atom selection shows 4 rows and a dihedral angle in the fourth row.

## Launch command

Use the checkout directly so the updated source and GTK compatibility layer are loaded:

```bash
pkill -f p4v.py
cd /home/qli/p4vasp
PYTHONPATH="$PWD/lib:$PWD/src" P4VASP_HOME="$PWD" /usr/bin/python3 p4v.py
```

# p4vasp 修复记录 — 2026-09-07

以下是本次会话中完成的结构可视化和 Measure（测量）界面修复记录。

## 已修复的问题

- 结构查看器现在使用白色背景，并将晶胞/超晶胞边线显示为黑色，使原子和晶胞边界都更清晰。
- `atomtypes.xml` 中的元素原子颜色已更新为用户要求的 Jmol 风格颜色。
- Structure Window Control 工具栏新增了 Side（侧视图）按钮；选择 Top（俯视图）或 Side 后会立即重绘结构。
- 原子球大小和箭头大小滑块现在使用兼容 GTK3 的 Adjustment API。修改 sphere size 滑块后，界面中的原子半径会同步更新。
- Measure 小程序在尚未分配活动结构的初始化阶段可以安全处理，不再触发测量表初始化错误。
- 打开 Measure 小程序时，默认选中 Z-matrix（Z 矩阵）显示模式。
- 修复了选择三个或四个原子时的 Measure 表格布局。此前表格内部实际已生成所有行，但 GTK3 只分配了表头和两行的高度，导致 angle（角度）和 dihedral（二面角）所在的行被隐藏。现在表格会填满可用的垂直空间。

## 验证结果

- 修改后的 Python 文件均可成功编译。
- 内置测试套件：**51 个测试全部通过**。
- GTK 回归测试确认：
  - 选择三个原子时显示 3 行，第三行显示角度。
  - 选择四个原子时显示 4 行，第四行显示二面角。

## 启动命令

请直接运行当前项目目录，确保使用最新的源代码和 GTK 兼容层：

```bash
pkill -f p4v.py
cd /home/qli/p4vasp
```
