# p4vasp update — 2026-11-07

## English

### ASE structure import from the command line and Open

- Requested: load non-VASP structures with commands such as `p4v test.xyz`, using ASE; when no cell exists, calculate the molecular extent and add 10 Å on both sides.
- Added `ase_import.py` and `ASESystemPM` through the shared `getSystem` dispatch used by CLI and File/Open. Supported extensions: xyz, extxyz, cif, pdb, mol, sdf, xsf and traj. Existing directory/DOSCAR/XML/POSCAR dispatch remains intact. Source builds reuse the optional ASE environment/override, keeping ASE out of the GTK interpreter. New Windows builds route to the bundled worker's `--read-structure`; format modules and a future frozen import check are included.
- Cell-free structures receive a Cartesian box of axis span + 20 Å, translated to exactly 10 Å padding at either end. A single atom receives a 20×20×20 Å box. Complete cells and coordinates remain unchanged, atom order is retained, and supported multi-frame formats use the last frame. Partial cells, empty structures, non-finite coordinates/cells and unknown elements are rejected. MOL/SDF use ASE's single-structure readers. Original files are never rewritten; import is bounded to 60 seconds and 100,000 atoms.
- The imported system contains geometry and an empty INCAR, without borrowing neighboring VASP calculation results. Original PBC is retained as import metadata; p4vasp's existing cell/repetition display still applies. Arbitrary extra properties, bonds, charges and full trajectories are not translated into complete scientific inputs. File/Open errors now show the cause and preserve the active system; CLI import errors no longer abort initialization.

### Vibrational analysis, thermochemistry and signed mode displacement

- After design approval, added the left Vibrations toolbar button and Analysis menu, a thin vibrations.glade host, VibrationsApplet and an embedded GTK/Cairo interactive 3D projection beside the complete parsed frequency list. Clicking a mode starts schematic animation; drag/wheel rotate/zoom. Play/pause, amplitude and period affect only the display copy. This is independent of native FLTK Show/Build; timers stop on unmap and workers are cancelled on destruction/source replacement.
- Added VibrationSystemPM and a worker parser for frequency OUTCAR, shared by CLI/main Open; the panel can also open its own analysis source or locate OUTCAR alongside the active system. Uses mode-table equilibrium coordinates and the final mode group; physical displacement vectors are used without further normalization, otherwise dynamical-matrix eigenvectors are divided by sqrt(OUTCAR POMASS). Validates rows/indices/finite data/cell/species and matching-reference degrees of freedom. Matching POSCAR/CONTCAR provides selective flags; otherwise export requires explicit unconstrained confirmation. Reduced mode sets warn for review. No fallback to older complete groups on a truncated final group.
- The imaginary-mode slider is dimensionless, -1..1 in 0.1 steps: Rnew=Roriginal+scale*displacement. It does not mean Angstrom, renormalize the maximum, or accumulate changes. Slider/Zero pause playback. Saving uses the static slider value, preserves cell/order/available flags, records mode/frequency/scale and exclusively creates a new POSCAR. It does not overwrite source files, replace the editable system, guarantee removal of a spurious imaginary mode or generate dimer direction blocks.
- Added ASE HarmonicThermo F corrections and IdealGasThermo G corrections through the isolated worker, with 90-second timeout/cancellation. Exposed T, gas P/geometry/symmetry/electronic spin S, optional electronic energy, mode selection, an explicit real-frequency floor and imaginary tolerance (both default zero). Minimum/first-order TS require zero/one significant imaginary mode; imaginary frequencies never enter the harmonic sums by absolute value. Exclusions require confirmation; gas vibration counts and geometry are checked. Reports show ZPE/U/H/S/TS/correction and optional total free energy; JSON retains selection/exclusions/effective frequencies/settings, and editing settings invalidates stale results.
- Seven backend tests passed, including independent harmonic formulas, analytic gas pressure/symmetry/spin changes, mass conversion, signed Scale/flags/nonaccumulation, malformed/truncated data and mismatched constraints. Actual Linux Frame CLI/toolbar, embedded drawing, mode animation, Scale/real POSCAR dialog, F and G worker/UI calculations, JSON save, OUTCAR chooser, missing-flag confirmation, panel reentry, cancellation/destruction passed. Rendered mapped-GTK widget screenshots were inspected; the initial desktop Gdk capture was black and is not visual evidence. The test chooser was changed to wait for path readiness rather than a fixed delay.
- Also passed three BulkTask, three DOSCAR, 57 basic, two frozen-routing, five ASE-import, seven updater, eight GTK, 33 applet startup (excluding GLUT) and four existing startup checks; XML/compilation/diff checks passed. Previous Windows releases and unrelated user files remain untouched.

## 中文

### 命令行与 Open 通过 ASE 导入结构

- 用户要求：以 `p4v test.xyz` 等命令读取非 VASP 结构，调用 ASE；无晶胞时计算分子跨度，两侧分别增加 10 Å。
- 新增 `ase_import.py` 和 `ASESystemPM`，接入 CLI 与 File/Open 共用的 `getSystem`。支持 xyz、extxyz、cif、pdb、mol、sdf、xsf、traj，保留目录／DOSCAR／XML／POSCAR 原分流。源码版复用可选 ASE 环境／解释器覆盖，不向 GTK 解释器导入 ASE；新版 Windows 构建通过随包 worker 的 `--read-structure` 读取，并补齐格式模块与下次冻结验收断言。
- 无晶胞时按三个笛卡尔跨度分别加 20 Å，平移后最外侧原子到两边盒壁各 10 Å；单原子为 20×20×20 Å。保留完整晶胞、坐标和原子顺序；支持多帧的格式读取最后一帧。部分晶胞、空结构、非有限坐标／晶胞及未知元素明确拒绝。MOL／SDF 使用 ASE 的单结构读取器。原文件不改写，读取限时 60 秒、最多 100,000 原子。
- 导入系统提供几何与空 INCAR，不借用相邻 VASP 计算结果。原 PBC 保存在导入信息中，显示仍沿用 p4vasp 原有晶胞／重复规则；扩展属性、键级、电荷和完整轨迹不承诺转换为完整计算输入。File/Open 报错显示原因并保留当前系统，CLI 导入失败不再中断初始化。
