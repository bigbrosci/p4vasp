## English

### First ASE Surface builder in Models

- Replace the empty surface tab with a lazily created, scrolled builder: common fcc/bcc/hcp metal presets, explicit Bulk-result snapshot or POSCAR/CIF source, Miller indices, layers, in-plane repetitions, vacuum per side and fixed bottom geometric layers. Reuse the existing isolated ASE transport/preview/new-folder dialogs; no ASE in GTK or pymatgen dependency.
- Use ASE build.surface/preset builders, get_layers and FixAtoms. Custom indices refer to the input cell, not an automatically standardized conventional cell; equivalent and geometric layer counts differ. Replace old input masks, group species stably and retain aligned flags/layer metadata. Validate finite/nondegenerate cells, parameters and 10000-atom limit. Default Cu(111) yields 16 atoms/8 fixed. Source structures/files remain unchanged.
- Native preview rings identify fixed atoms; clear shared preview selection before each new model. Save POSCAR and surface.json with portable bulk input/parameters/layer numbers in a new non-overwriting folder. No standalone replay script, complete VASP inputs, termination enumeration, stability/polarity validation or adsorbate placement in this first version.
- Actual ASE six-test suite passes presets, analytic layer spacing/vacuum/masks, custom/negative indices, CIF/mixed-species portable inputs, invalid requests and source worker protocols. Real GTK integration passes asynchronous responsiveness, displayed indices, source selection, native preview, file/save/no-overwrite, stale-result invalidation, simulated cancellation callback and explicit page destruction. Fixed chooser str/Path handling; offscreen-parent/destruction fixture failures were corrected separately. Native process cancellation/timeout is covered by three existing transport tests, not claimed as a full application-shutdown test.
- Models lazy/state, Resources editing, nine GTK, 58 base, 33 applet, three dependency-tool/catalog checks and compile/diff/doc checks pass. Inspected page and native preview screenshots; logs /tmp/p4vasp-surface-{core,gtk,task,lazy,resources,gtk-base,base,smoke,dependencies}.log. ASE/NumPy deprecation and existing cmatrix shutdown warnings remain.
- Windows dispatcher/spec/future packaged diagnostics gain Surface support, but no EXE build or Windows/macOS acceptance. Existing ASE catalog purpose/source references updated without environment/version change or new snapshots. Memory/architecture/install/usage synchronized; November 21 Windows package does not include Surface.

- 空surface标签改为惰性滚动建模页：fcc/bcc/hcp常用金属面、Bulk结果快照或POSCAR/CIF来源、晶面指数、层数、面内重复、每侧真空和底部几何层固定。复用独立ASE进程/原生预览/新目录对话框，GUI不导入ASE，不新增pymatgen依赖。
- 调用ASE标准面/通用surface、get_layers、FixAtoms；自定义指数以输入晶胞为准，不自动常规胞化，等价层与几何层区分。替换旧固定掩码，元素稳定分组保持F/T和层号对齐，校验参数/有限退化/10000原子。默认Cu(111)16原子、8固定，源结构/文件不修改。

- Windows dispatcher/spec/未来成品诊断接入Surface，但不构建EXE、不验收Windows/Mac。ASE目录用途/源码索引同步，无环境/版本变化，不采新快照。memory/架构/安装/用法同步，11月21日Windows包不含本功能。
