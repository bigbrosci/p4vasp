# p4vasp fixes — 2026-09-23

This update summarizes today's STM interface fixes, INCAR generator and saving workflow, and project-wide GTK3 runtime migration. It records the final behavior after all revisions.

## Fixed issues

- Restored the STM panel's vertical toolbar by allowing it to fill the available height, preventing its buttons from collapsing into an overflow arrow. Reduced numeric entry widths so the settings fit the panel.
- Fixed slider ranges, initial values, decimal precision, and initial option-menu selections in the GTK3 resource loader. STM controls now use GTK3 Adjustment APIs and initialize from the viewer's state. Moving the position slider without charge data no longer divides by zero; density and smoothing controls now have the required math imports.
- Added an **INCAR** button beside Build and an **Edit → INCAR generator** menu entry, based on the older Q-robot GUI at `/home/lqlhz/bin/qrob/incar_gui`. The native GTK panel includes Functional, Correction, Model, System, and Tasks presets, standard sections, a live preview, and custom `TAG = value` overrides. It requires no Flask, browser, or ASE dependency.
- Preset selection prevents conflicting primary tasks, functionals, models, and dispersion corrections while allowing supplemental tasks. Each INCAR tag is emitted once, with custom values taking highest priority. Presets are stored in `data/incar/presets.json`; usage is documented in `data/incar/README.md`.
- Removed the INCAR geometry selector and summary. The panel starts with no selections, and **Refresh** clears all preset/task selections, standard-section selections, and custom parameters.
- Added an independent **MAGMOM** task. It reads the active initial/opened POSCAR or Build structure, preserves POSCAR species-block order, and initializes every moment to zero. A comment lists the elements and their counts. Without an open structure, it leaves `MAGMOM =` blank. ISPIN does not automatically select MAGMOM; custom MAGMOM values override the generated line while retaining the element comment. For example:

  ```text
  # Cu (64), C (1), H (2), O (3)
  MAGMOM = 64*0  1*0  2*0  3*0
  ```

- DFT+U helpers use the active initial structure and Q-robot U/J defaults, with manual custom overrides available.
- Replaced the oversized INCAR save chooser with a compact dialog containing explicit **Filename** and **Folder** fields, **Cancel** and **Save** buttons, and normal window close controls. The filename defaults to `INCAR` and can be changed to `INCAR_test`, `INCAR_1`, `INCAR_2`, etc. Existing files require overwrite confirmation; write errors keep the dialog open for correction.
- Added **Browse…** beside the Folder field. The compact folder browser supports double-click directory navigation, **Up**, **Home**, **Select folder**, and **Cancel**. Selecting a directory updates the folder field and preserves the entered filename.
- Centralized Python GUI imports through `p4vasp.gtk3`, explicitly requiring PyGObject and GTK3. Legacy `gtk`, `gobject`, `pango`, GraphCanvas, and PIDDLE GTK import paths now forward to GTK3 implementations; startup no longer requests PyGTK2.
- Replaced GTK1/GTK2 plot drawing with `p4vasp.piddle.piddleGTK3`, using Cairo image surfaces, GTK draw events, and PangoCairo text, including rotated labels. Fixed plot resizing, keyboard zoom, mouse interaction, backgrounds, cursor names, and canvas signal cleanup.
- Fixed GTK table-model insertion, deletion, and change notifications; empty Builder, Phonon, and database trees; phonon tuple-label editing; and selective-dynamics checkbox refresh in Build. Corrected lattice callbacks that could run on partially filled cells, text-buffer access, export chooser APIs, selection access, and the trajectory timer.
- Improved resource loading for frame labels, notebook tabs, numeric properties, progress orientation, sizes, and combo boxes. Existing `data/glade2/*.glade` layouts are retained and adapted into GTK3 widgets without a GTK2/libglade runtime. Some GTK3-supported deprecated widgets remain; historical generated documentation was not rewritten. The native FLTK/OpenGL structure windows and separate GLUT k-point viewer remain independent renderers. Migration details and test commands are in `doc/GTK3-migration.md`.
- Updated Ubuntu dependency/build checks to include `python3-gi-cairo` and verify `gi.require_foreign("cairo")`. The `ubuntu-start.sh` and `macos-start.sh` wrappers delegate to their bootstrap scripts, so no additional wrapper changes are needed. The macOS bootstrap already includes `gtk+3`, `pygobject3`, and `py3cairo`. This project requires **GTK3**; installing GTK4 does not replace the GTK3 dependency.

## Verification

- Modified Python files compile, shell scripts pass syntax checks, and `git diff --check` passes.
- Bundled test suite: **57 tests passed**, including six INCAR regression tests.
- GTK3 regression suite: **7 tests passed**. All **40 Glade UI resources** load without property-conversion errors, and all **31 GTK applet startup checks** pass.
- STM checks covered initialization, direction/mode selection, cell replication, mode switching, and position handling without charge data. The rendered panel was inspected for toolbar/settings visibility. Viewer rendering was stubbed in the control check; no PARCHG calculation was tested.
- INCAR checks covered toolbar activation and panel switching, preset exclusion, Refresh reset, zero/blank MAGMOM, element counts and order (including repeated species blocks), manual overrides, custom filenames, save/cancel, and folder browsing/navigation.
- Real application startup and DOS/bands → INCAR → Build → INCAR toolbar switching passed. The installed system GTK3/Cairo dependencies were verified with `/usr/bin/python3`. macOS was not run or tested in this environment.
- Graph and applet checks use synthetic data and an empty in-memory database; they do not validate scientific results or external database connectivity.
- Known remaining issue: the optional, separate GLUT k-point viewer reports an OpenGL context initialization error in this environment. It is not included in the 31 passing GTK applet checks; the smoke runner's `--include-glut` option exposes this check.


# p4vasp 修复记录 — 2026-09-23

以下汇总今天完成的 STM 界面修复、INCAR 生成与保存功能，以及项目运行时向 GTK3 的整体迁移。本文记录所有调整完成后的最终行为。

## 已修复的问题

- 修复 STM 面板的垂直工具栏布局，使其填满可用高度，避免按钮折叠到溢出箭头中。缩小数值输入框宽度，使设置项适应面板尺寸。
- 修复 GTK3 资源加载器对滑块范围、初始值、小数精度及选项菜单初始选择的处理。STM 控件改用 GTK3 Adjustment API，并根据查看器状态初始化。没有电荷数据时移动位置滑块不再产生除零错误；补充了电子密度及平滑控制所需的数学函数导入。
- 参考旧版 Q-robot GUI（`/home/lqlhz/bin/qrob/incar_gui`），在 Build 旁新增 **INCAR** 按钮，并添加 **Edit → INCAR generator** 菜单入口。原生 GTK 面板包含 Functional、Correction、Model、System 和 Tasks 预设、标准参数区、实时预览及自定义 `TAG = value` 参数，无需 Flask、浏览器或 ASE。
- 预设选择会避免主要任务、泛函、模型和色散修正之间的冲突，同时允许选择附加任务。每个 INCAR 参数只输出一次，自定义值具有最高优先级。预设保存在 `data/incar/presets.json`，使用说明见 `data/incar/README.md`。
- 移除 INCAR 面板的几何结构选择器及结构摘要。面板初始状态不选中任何选项；点击 **Refresh** 会清空全部预设/任务选择、标准参数区选择及自定义参数。
- 新增独立的 **MAGMOM** 任务。它读取当前系统的初始结构、已打开的 POSCAR 或 Build 结构，保留 POSCAR 中元素分组的顺序，并将所有初始磁矩设为零。注释行列出元素及其原子数。未打开结构时保留空白的 `MAGMOM =`。ISPIN 不再自动选择 MAGMOM；手动填写的自定义 MAGMOM 会覆盖自动生成值，同时保留元素注释。例如：

  ```text
  # Cu (64), C (1), H (2), O (3)
  MAGMOM = 64*0  1*0  2*0  3*0
  ```

- DFT+U 辅助功能使用当前初始结构和 Q-robot 的 U/J 默认值，同时支持自定义参数覆盖。
- 将过大的 INCAR 保存窗口替换为紧凑对话框，明确显示 **Filename（文件名）**、**Folder（文件夹）** 输入框、**Cancel（取消）**、**Save（保存）** 按钮及正常的窗口关闭控件。默认文件名为 `INCAR`，可改为 `INCAR_test`、`INCAR_1`、`INCAR_2` 等。覆盖已有文件前会要求确认；写入失败时保留对话框，便于修改后重试。
- 在 Folder 输入框旁新增 **Browse…（浏览）** 按钮。紧凑文件夹浏览器支持双击进入目录、**Up（上一级）**、**Home（主目录）**、**Select folder（选择文件夹）** 和 **Cancel（取消）**。选择目录后自动更新保存路径，并保留已输入的文件名。
- Python GUI 统一通过 `p4vasp.gtk3` 导入，明确使用 PyGObject 和 GTK3。旧的 `gtk`、`gobject`、`pango`、GraphCanvas 和 PIDDLE GTK 导入路径转接到 GTK3 实现；启动过程不再请求 PyGTK2。
- 使用 `p4vasp.piddle.piddleGTK3` 替换 GTK1/GTK2 绘图实现，采用 Cairo 图像表面、GTK 绘制事件及 PangoCairo 文字渲染，并支持旋转文字。修复图形缩放尺寸、键盘缩放、鼠标交互、背景、光标名称及画布信号清理。
- 修复 GTK 表格模型的插入、删除和修改通知，以及 Builder、Phonon 和数据库树为空时的处理；修复声子元组标签编辑和 Build 中选择性动力学复选框的刷新。修正晶格输入尚未完整时触发的回调、文本缓冲区读取、导出文件选择器 API、选择状态读取及轨迹定时器。
- 改进框架标签、Notebook 标签页、数值属性、进度条方向、控件尺寸和组合框的资源加载。保留 `data/glade2/*.glade` 布局文件，由适配层创建 GTK3 控件，运行时不再依赖 GTK2/libglade。部分 GTK3 仍支持的已弃用控件继续保留；历史生成文档未整体重写。原生 FLTK/OpenGL 结构窗口及独立的 GLUT k 点查看器仍使用各自的渲染实现。迁移说明及测试命令见 `doc/GTK3-migration.md`。
- Ubuntu 依赖和构建检查已加入 `python3-gi-cairo`，并验证 `gi.require_foreign("cairo")`。`ubuntu-start.sh` 和 `macos-start.sh` 调用各自的引导脚本，因此无需额外修改这两个启动包装脚本。macOS 引导脚本已包含 `gtk+3`、`pygobject3` 和 `py3cairo`。本项目需要 **GTK3**，安装 GTK4 不能替代 GTK3 依赖。
