# p4vasp update — 2026-10-24

## English

- Added `ubuntu_install.sh` as the common installation entry for Ubuntu/Debian, other Linux and macOS. Kernel/distribution detection selects the existing backend automatically; legacy entry points remain available.
- Ubuntu/Debian uses apt. Other Linux preserves the former `--skip-apt` workflow and requires preinstalled dependencies; automatic dnf/pacman/zypper installation is not included. macOS uses the existing Homebrew/venv flow and requires Homebrew and Xcode Command Line Tools.
- Added unified help, `--skip-deps` aliases and a non-mutating `--dry-run`; forwarded build/launch options and application arguments safely. Unsupported kernels, unknown installer options, contradictory dependency flags and unsupported dependency-only requests produce errors.
- Default installation rebuilds the native extension, addressing the need to compile new mouse-selection functionality on another computer after updating source.
- Updated `install.md` and `memory.md`. Nine isolated routing/argument tests, shell syntax checks and the local Linux dry run passed. No system packages were installed during verification; actual macOS and non-Debian builds remain untested.

## 中文

- 新增统一安装入口 `ubuntu_install.sh`，自动识别 Ubuntu/Debian、其他 Linux 和 macOS，并调用已有安装流程。旧入口仍保留兼容。
- Ubuntu/Debian 使用 apt；其他 Linux 自动采用此前的 `--skip-apt` 路径，需预先安装依赖，本次未新增 dnf/pacman/zypper 自动安装。macOS 继续使用 Homebrew 和虚拟环境流程，需先准备 Homebrew 与 Xcode 命令行工具。
- 提供统一帮助、`--skip-deps` 及兼容别名、无修改的 `--dry-run` 预览；保留编译／启动选项并安全转发应用参数。不支持的系统、未知安装选项、冲突参数及不支持的仅依赖安装请求会明确报错。
- 默认重新编译原生扩展，确保在其他电脑更新源码后，鼠标框选等 C++ 功能可以进入本地编译版本。
- 更新 `install.md` 和 `memory.md`。9 项隔离分流／参数测试、Shell 语法检查及本机 Linux 预览通过。验证期间未安装系统软件，未实际执行 macOS 或非 Debian 系的完整编译安装。
