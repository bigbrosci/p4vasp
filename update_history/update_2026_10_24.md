# p4vasp update — 2026-10-24

## English

- Added `ubuntu_install.sh` as the common installation entry for Ubuntu/Debian, other Linux and macOS. Kernel/distribution detection selects the existing backend automatically; obsolete entry wrappers were subsequently removed as requested.
- Ubuntu/Debian uses apt. Other Linux preserves the former `--skip-apt` workflow and requires preinstalled dependencies; automatic dnf/pacman/zypper installation is not included. macOS uses the existing Homebrew/venv flow and requires Homebrew and Xcode Command Line Tools.
- Added unified help, `--skip-deps` aliases and a non-mutating `--dry-run`; forwarded build/launch options and application arguments safely. Unsupported kernels, unknown installer options, contradictory dependency flags and unsupported dependency-only requests produce errors.
- Default installation rebuilds the native extension, addressing the need to compile new mouse-selection functionality on another computer after updating source.
- Updated `install.md` and `memory.md`. Nine isolated routing/argument tests, shell syntax checks and the local Linux dry run passed. No system packages were installed during verification; actual macOS and non-Debian builds remain untested.

### Obsolete entry-point cleanup

- Removed `ubuntu-start.sh`, `macos-start.sh`, and `install/install-ubuntu-dependencies.sh`. Use `bash ubuntu_install.sh` or `bash ubuntu_install.sh --deps-only` instead.
- Retained both installation backends, platform/shared build scripts, and `run-p4vasp.sh`. Updated installation instructions, backend help and maintenance memory; earlier dated notes remain historical records.
- Rechecked all remaining shell scripts for syntax, nine installer routing tests, backend help and the unified dry run. No system packages were installed and no GUI was launched.

### Launcher rename

- Renamed `run-p4vasp.sh` to `p4v.sh` without changing launcher behavior. Updated both installation backends, installation/GTK3 documentation and memory to use the new name.
- Daily startup: `bash p4v.sh`. Existing shell aliases must replace the old filename with `p4v.sh`.
- Shell syntax checks, nine installer-routing tests and a mocked launcher check for argument/environment forwarding and exit status passed. No GUI was opened for this filename-only change.

### Unified installer rename

- Renamed `ubuntu_install.sh` to `install.sh` to reflect its Linux/macOS scope; installation behavior is unchanged. Updated help, backend hints, routing tests, installation documentation and maintenance memory.
- Current commands: `bash install.sh` to install/build and `bash p4v.sh` for daily startup. The old installer filename is no longer present.
- Nine routing tests, shell syntax checks and the renamed entry's dry run passed. No package installation or GUI launch was performed.

## 无窗口 PNG 导出 / Headless PNG export

### 中文

- 新增 `p4v POSCAR -o top.png`，在加载 GTK 前进入独立 Cairo 渲染，不打开窗口、不需要显示服务器或 ASE；不带输出参数仍启动 GUI。
- 支持 top/front/side、按轴旋转、图片尺寸、透明背景、晶胞显示和原子半径倍率。已有 PNG 需要 `--force` 才会覆盖，不修改输入结构。
- 沿用项目元素颜色，使用正交球体绘制；暂不包含化学键、标签和周期复制，遮挡采用深度排序，并非 GUI 截图。详细选项和旋转约定见 `doc/render-cli.md`。
- 8 项专项测试通过，覆盖无显示启动、禁止 GUI 模块导入、旋转、缩放因子和覆盖保护；已查看生成图片。未验证 macOS 和交互 GUI。

### English

- Added `p4v POSCAR -o top.png`, dispatching to an independent Cairo renderer before GTK loads. No window, display server or ASE is required; ordinary GUI startup remains available without output options.
- Supports top/front/side, ordered axis rotations, dimensions, transparency, cell visibility and radius scaling. Existing PNGs require `--force`; input structures are preserved.
- Uses project colors with orthographic shaded spheres, approximate depth ordering, and no bonds, labels or periodic replicas. This is not a GUI screenshot. Options and conventions are documented in `doc/render-cli.md`.
- Eight focused tests passed, including display-free startup, blocked GUI imports, rotations, scale factors and overwrite protection. A generated image was visually inspected. macOS and interactive GUI behavior were not tested.

### 默认透明背景 / Transparent background by default

- PNG 导出默认使用透明背景；保留 `--transparent`，新增 `--white-background` 用于不透明白色背景。9 项专项测试通过，包括默认透明和显式白色背景的像素检查。
- PNG exports now default to transparency. `--transparent` remains supported; `--white-background` selects opaque white. All nine focused tests passed, including pixel checks for both backgrounds.

## 图片模型与画质 / Image models and quality

- 新增球棍、棍状和基于项目半径的填充模型，保留默认球体模式；填充模型不是严格范德华半径模型。新增亮度、键粗细、成键距离倍率与超采样选项，默认透明背景和 2 倍超采样。
- Added ball-stick, stick and project-radius filling models alongside default spheres; filling is not a calibrated vdW model. Added brightness, bond radius/cutoff and supersampling controls; transparency and 2x sampling are defaults.
- 成键仅限输入原子，暂不含跨周期边界的键；深度遮挡仍为近似，GUI 未改动。11 项专项测试通过，并查看了球棍图片。
- Bonds connect input atoms only, without periodic boundary bonds; depth ordering is approximate and GUI behavior is unchanged. Eleven focused tests passed and a ball-stick image was visually inspected.

- PNG export now replaces existing output by default. `--force` remains compatible; `--no-clobber` opts out. Replacement happens after successful rendering, and input structures remain protected. All eleven renderer tests passed.
