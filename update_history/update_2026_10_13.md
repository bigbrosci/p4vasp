# p4vasp updates — 2026-10-13

## English

### Toggle box selection and clear selection with Escape

- **Shift + left drag** now toggles each atom whose center projects inside the rectangle: selected atoms become unselected and unselected atoms become selected. Atoms outside the rectangle remain unchanged. This replaces the October 12 additive-only behavior. Occluded atoms remain eligible; explicitly hidden atoms remain excluded.
- **Escape while idle** clears the complete selection without closing the structure window. **Escape during a drag** cancels only that rectangle, preserving the previous selection. Ordinary rotation and Space single-atom toggling remain available.
- Updated `src/VisStructureDrawer.cpp`: removals are compacted in one pass while preserving the order of remaining selections. A single selected/deselected event synchronizes the complete result with Python, including an empty selection. Existing protection against FLTK's Escape-to-close shortcut is retained.
- Rebuilt the native extension locally; restart p4vasp to load the change. Other checkouts must rebuild before launching.

### Verification

- Native FLTK/OpenGL regression passed for repeated toggle-on/off, reversed and mixed rectangles, unchanged selections outside the box, periodic images, hidden/occluded atoms, notification on deselecting the last atoms, idle Escape via key/shortcut delivery, and cancellation preserving a nonempty selection. Existing camera, Space and window-close checks also passed.
- 57 bundled tests and 31 applet startup checks passed. `git diff --check` passed.
- Tests use synthetic structures and events in the native viewer. All downstream applet workflows were not manually tested. The full GTK resource suite was not rerun; its previously documented property-conversion failures remain unresolved. macOS and HiDPI displays were not tested.

## 中文

### 框选反转状态，Esc 清空选择

- **Shift + 鼠标左键拖动**改为逐个反转矩形内原子的选中状态：已选中的取消，未选中的选中。矩形外的原子保持原状态。此行为替代 10 月 12 日的仅追加框选。仍按原子中心的屏幕投影判断，包含被遮挡原子，但不包含主动隐藏的原子。
- **未拖动时按 Esc**：清空全部选择，保持模型窗口打开。**拖动时按 Esc**：仅取消当前矩形，保留之前的选择。普通旋转和 Space 单原子切换继续可用。
- 修改 `src/VisStructureDrawer.cpp`：一次整理被取消的原子，保留其他选择的顺序；每次变化只发送一次选择／取消通知，将完整结果（包括空选择）同步至 Python。保留此前对 FLTK 默认 Esc 关闭快捷键的拦截。
- 本机原生扩展已重新编译，重启 p4vasp 后生效；其他项目副本需先重新编译再启动。

### 验证结果

- 原生 FLTK/OpenGL 回归测试通过，覆盖重复选中／取消、反向及混合矩形、框外选择不变、周期复制、隐藏／遮挡原子、取消最后一批原子后的通知、按键／快捷键形式的 Esc 清空，以及取消拖动时保留非空选择。原有视角、Space 和窗口关闭检查也通过。
- 57 个基础测试和 31 个 applet 启动检查通过，`git diff --check` 通过。
- 测试使用原生查看器中的合成结构和输入事件，未对所有下游 applet 操作进行人工测试。本次未重跑完整 GTK 资源套件；此前记录的属性转换失败仍未修复。未测试 macOS 或 HiDPI 显示器。
