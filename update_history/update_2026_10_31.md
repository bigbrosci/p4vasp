# p4vasp 更新 — 2026-10-31

## 中文

### 按当前视角用方向键移动选中原子

- 保留 Edit → Move atoms 的原向量 Move／Copy 流程，新增模型窗口方向键编辑：先选中原子，再调整视角，←／→ 沿屏幕水平方向，↑／↓ 沿屏幕竖直方向平移。使用按键时的相机旋转，旋转模型后方向随视角改变。
- 默认每次 0.1 Å，用户已确认。Move 面板新增 Arrow-key step (Å)，支持 0.001–10 Å，会话内共享；步长按实际长度计算，不随缩放或透视改变。
- 原生事件快照记录来源窗口、相机方向和选中原子的去重编号。选同一原子的多个周期副本只编辑原胞原子一次；按键后改变选择或相机不会改写已排队请求的载荷。
- Python 将修改写回来源窗口所属系统的初始／Build 结构，并刷新同系统面板。最终结构、轨迹、原胞和 STM 视图不执行该编辑。空选择、修饰键方向组合及鼠标拖动不触发移动。
- 保留原坐标表示、晶胞/比例、原有选择性动力学标记、相机和原子选择；不自动换胞或改固定标记。按原保存流程可保存修改。周期居中显示仍按原查看模式处理。

- `lib/p4vasp/applet/MoveApplet.py`：在现有 Glade 容器中加入步长控件，原菜单、资源和向量按钮保留。
- 原生头文件及源代码、src/lib Python 代理和生成的绑定已同步；本机 SWIG 为 4.4.0，旧生成件为 4.4.1，重新生成包含工具版本差异。本机 Linux 已重新编译。

- 按用户要求保留普通箭头平移，新增 Shift＋上下围绕穿过所选原子质心的当前视角 X 轴、Shift＋左右围绕 Y 轴旋转，每次固定 5°。轴随相机方向改变，右手规则下上/左负、下/右正；原 Rotate atoms 的历史角度约定未改。Move 面板添加操作提示，平移步长不控制旋转角。

- 本机 Linux 原生重编译通过。坐标专项扩展到 7 项并通过：不等质量中心区别于几何中心、正逆旋转、默认 5°、距离与质心不变、不同坐标/比例、标记保留、无质量拒绝、元素表回退和单原子。读取质量表时出现已有 ODP 对象释放警告，未改该独立实现。
- 原生 Shift/普通箭头的多视角、缩放、透视、选择/相机快照及已有交互回归通过。真实 GTK 合成 H/He/C 模型验证了 5°、质心、未选原子、相机/选择、只读视图及保存标记；面板绘制已查看。测试夹具最初复用旧结构或替换 Property 而非 SetupPM 实际属性，已改为新结构赋给真实属性再验证，未把夹具错误当作应用缺陷。

## single atom 周期表与三文件输入生成

- 用户要求在 Models 的 single atom 中选择元素后生成 INCAR、KPOINTS、POSCAR。新增 118 元素周期表，包含镧系／锕系分行；选中高亮，未选择时禁用 Generate inputs。其余三个标签页仍空。
- 点击 Generate inputs 后通过紧凑弹窗填写新目录名称和父目录（可 Browse），默认如 Fe_single_atom；取消不写，同名目录拒绝覆盖。写入错误时清理本次目录内已创建文件，成功显示输出路径，不改当前加载模型或源预设。
- 用户澄清其余参数以 p4vasp 的 INCAR 生成功能为准。助手只读定位到 qrob/actions_py/in.py→brain/incar.py，并确认当前基础参数与内部 presets.json 一致；实现复用内部 load_presets／generate_incar 的全部 Standard，不依赖外部脚本。覆盖 ISPIN=2、ALGO=ALL、NELM=500，移除 MAGMOM；不启用额外任务或元素磁矩／U／J，其他基础参数保留，SYSTEM 写所选元素。
- POSCAR 为 13×14×15 Å 正交晶胞，单原子在 Direct (0.5,0.5,0.5)，笛卡尔 (6.5,7,7.5) Å；Gamma 1×1×1 KPOINTS，偏移为零。仅生成请求的三个文件，不生成赝势或运行计算。
- 实现为 single_atom_inputs.py、gtk3/single_atom.py，由 ModelsApplet 第一页装入，复用现有目录浏览与工作区限高逻辑。指南与 memory 同步。
- 本机 Linux 5 项专项通过，覆盖118元素结构读回、坐标和晶胞、参数继承与覆盖／MAGMOM排除、K网格、新目录／既有目录保护、非法路径与写入失败清理；6 项 INCAR 生成、57 基础、32 applet 启动通过。实际 X11 GTK 测试通过选择切换、按钮与选中状态、紧凑弹窗创建／取消和 Generate 动作接线；主界面及目录窗口截图已查看，实际 Frame 仍隐藏 System／Selection、切回 Builder 恢复。
- 验证只在临时目录生成输入，不代表 VASP 能量／磁态／收敛性或其他平台验证。未测完整 GTK 套件，Windows 打包继续暂停。

## gas phase 本地 XYZ 分子库与输入生成

- 用户接受标准化本地接口：`data/models/gas_phase/` 单构型 XYZ，附 water／oxygen_triplet 示例及中文说明。第一行原子数，第二行 name/charge/multiplicity/units 元数据，后续元素符号与 Å 笛卡尔坐标。普通注释允许保留，缺电荷／多重度不猜测；错误文件显示文件名及行号，不影响其余条目。
- Models gas phase 页面进入时自动扫描，提供 Refresh、Open library folder、Preview 3D、Generate inputs。选择分子后可确认电荷、多重度、NELECT及晶胞，源文件未变时刷新保留人工输入；预览不变更当前系统，不加氢、重构配位或独立移动片段。bulk／surface 仍空，本次未加入名称查询或SMILES建模。
- 新 `gas_phase_inputs.py` 校验／分组／整体平移及生成；晶胞默认 max(13/14/15 Å, ceil(各向跨度+12 Å))，可调整且必须大于跨度。KPOINTS 为Gamma 1×1×1，POSCAR保留片段间距离，INCAR使用内部Standard并覆盖ISPIN2／ISMEAR0／SIGMA0.01／NUPDOWN=多重度−1，不设置MAGMOM或自动U/J。中性NELECT留空，带电必须依据真实POTCAR价电子填写整数NELECT，检查电子数与自旋奇偶，不从原子序数推算。NUPDOWN约束自旋差不保证自旋本征态或基态；修正与收敛性不自动决定。
- 复用并扩展紧凑输入目录弹窗及三文件新目录写入，既有单原子行为保留。不同或多帧XYZ、非有限坐标、未知元素、错误元数据均拒绝；生成前确认源结构／元数据未变化，已有目录不覆盖。
- 原生预览关闭专项曾复现段错误：StructureWindow.hide 在异步FL_HIDE前释放绘图对象。新预览改为会话共享独立窗口、对象保持存活、隐藏时VisSync；`p4v.py` 为该辅助窗口隔离选择／移动／关闭／激活事件。反复关闭重开与页面销毁通过，未改动旧通用hide实现。
- 本机Linux通过5项气相数据、5项单原子、6项INCAR、57基础及32 applet启动。实际X11 GTK／原生检查通过：列表坏文件／缺元数据、刷新保留、三维结构加载、合成事件路由引用真实窗口、真实保存弹窗带电导出、取消、关闭重开与销毁。初次事件测试使用未暴露的SWIG构造器，调整为模拟事件核验路由；未误报为应用缺陷。页面截图已查看。
