# p4vasp 更新 — 2026-10-31

## 中文

### 按当前视角用方向键移动选中原子

- 保留 Edit → Move atoms 的原向量 Move／Copy 流程，新增模型窗口方向键编辑：先选中原子，再调整视角，←／→ 沿屏幕水平方向，↑／↓ 沿屏幕竖直方向平移。使用按键时的相机旋转，旋转模型后方向随视角改变。
- 默认每次 0.1 Å，用户已确认。Move 面板新增 Arrow-key step (Å)，支持 0.001–10 Å，会话内共享；步长按实际长度计算，不随缩放或透视改变。
- 原生事件快照记录来源窗口、相机方向和选中原子的去重编号。选同一原子的多个周期副本只编辑原胞原子一次；按键后改变选择或相机不会改写已排队请求的载荷。
- Python 将修改写回来源窗口所属系统的初始／Build 结构，并刷新同系统面板。最终结构、轨迹、原胞和 STM 视图不执行该编辑。空选择、修饰键方向组合及鼠标拖动不触发移动。
- 保留原坐标表示、晶胞/比例、原有选择性动力学标记、相机和原子选择；不自动换胞或改固定标记。按原保存流程可保存修改。周期居中显示仍按原查看模式处理。

### 实现位置

- `src/VisWindow.cpp`：结构窗口键盘处理及相机方向换算。
- `src/include/p4vasp/VisBackEvent.h`、`src/VisBackEvent.cpp`：新增移动请求、快照和窗口归属。
- `p4v.py`、`lib/p4vasp/atom_movement.py`：事件分发、初始结构更新及实际长度换算。
- `lib/p4vasp/applet/MoveApplet.py`：在现有 Glade 容器中加入步长控件，原菜单、资源和向量按钮保留。
- 原生头文件及源代码、src/lib Python 代理和生成的绑定已同步；本机 SWIG 为 4.4.0，旧生成件为 4.4.1，重新生成包含工具版本差异。本机 Linux 已重新编译。

## Shift＋方向键：绕质量中心旋转

- 按用户要求保留普通箭头平移，新增 Shift＋上下围绕穿过所选原子质心的当前视角 X 轴、Shift＋左右围绕 Y 轴旋转，每次固定 5°。轴随相机方向改变，右手规则下上/左负、下/右正；原 Rotate atoms 的历史角度约定未改。Move 面板添加操作提示，平移步长不控制旋转角。
- 质心使用质量加权。优先采用结构质量，否则查元素表；无法确定正且有限的质量时提示并中止，不用几何中心替代。每次旋转前重新求质心，状态栏显示其实际 Å 坐标。全部新坐标先计算/验证，随后更新，保留初始结构的晶胞、比例、坐标模式和选择性动力学标记。
- 使用原生事件已有 index 标记旋转请求，复用来源窗口、轴方向和去重编号快照，无需新增绑定接口。只修改初始／Build 结构，不编辑最终/轨迹/原胞/STM 视图；单原子不移动，未选原子不动。周期副本去重，但不按周期最短距离重构跨边界分子，质心基于原胞当前坐标。
- 本机 Linux 原生重编译通过。坐标专项扩展到 7 项并通过：不等质量中心区别于几何中心、正逆旋转、默认 5°、距离与质心不变、不同坐标/比例、标记保留、无质量拒绝、元素表回退和单原子。读取质量表时出现已有 ODP 对象释放警告，未改该独立实现。
- 原生 Shift/普通箭头的多视角、缩放、透视、选择/相机快照及已有交互回归通过。真实 GTK 合成 H/He/C 模型验证了 5°、质心、未选原子、相机/选择、只读视图及保存标记；面板绘制已查看。测试夹具最初复用旧结构或替换 Property 而非 SetupPM 实际属性，已改为新结构赋给真实属性再验证，未把夹具错误当作应用缺陷。
- 57 个基础测试和 31 个界面启动检查再次通过；完整 GTK、真实用户模型及其他平台未测，Windows 打包继续暂停。重启本机程序后使用；其他 checkout 需先重新编译。
