# p4vasp 更新 — 2026-10-31

## 中文

### 按当前视角用方向键移动选中原子

- 保留 Edit → Move atoms 的原向量 Move／Copy 流程，新增模型窗口方向键编辑：先选中原子，再调整视角，←／→ 沿屏幕水平方向，↑／↓ 沿屏幕竖直方向平移。使用按键时的相机旋转，旋转模型后方向随视角改变。
- 默认每次 0.1 Å，用户已确认。Move 面板新增 Arrow-key step (Å)，支持 0.001–10 Å，会话内共享；步长按实际长度计算，不随缩放或透视改变。
- 原生事件快照记录来源窗口、相机方向和选中原子的去重编号。选同一原子的多个周期副本只编辑原胞原子一次；按键后改变选择或相机不会改写已排队请求的载荷。
- Python 将修改写回来源窗口所属系统的初始／Build 结构，并刷新同系统面板。最终结构、轨迹、原胞和 STM 视图不执行该编辑。空选择、修饰键方向组合及鼠标拖动不触发移动。
- 保留原坐标表示、晶胞/比例、原有选择性动力学标记、相机和原子选择；不自动换胞或改固定标记。按原保存流程可保存修改。周期居中显示仍按原查看模式处理。

### 实现位置

- `src/VisWindow.cpp`：结构窗口键盘处理及相机方向换算。
- `src/include/p4vasp/VisBackEvent.h`、`src/VisBackEvent.cpp`：新增移动请求、快照和窗口归属。
- `p4v.py`、`lib/p4vasp/atom_movement.py`：事件分发、初始结构更新及实际长度换算。
- `lib/p4vasp/applet/MoveApplet.py`：在现有 Glade 容器中加入步长控件，原菜单、资源和向量按钮保留。
- 原生头文件及源代码、src/lib Python 代理和生成的绑定已同步；本机 SWIG 为 4.4.0，旧生成件为 4.4.1，重新生成包含工具版本差异。本机 Linux 已重新编译。

### 验证

- 3 项坐标更新专项通过，覆盖直接/笛卡尔坐标、正比例/负体积/三分量比例、斜晶胞、重复编号、无效/空选择、可配置实际步长及保存后的选择性动力学标记。三分量比例的检查先转为分数坐标再归一化，避开原有 correctScaling 笛卡尔分支的独立 NameError；没有将该旧问题作为本次修复。
- 扩展原生回归通过：俯视/侧视/任意旋转下的四个方向，缩放与透视，周期编号去重，选择快照、相机快照、空选择与修饰键。原有框选、旋转、空格和 Escape 继续通过。
- 实际 GTK 面板检查通过：默认步长、控件修改后实际移动距离、源系统初始结构写回、相机/缩放与选择保留、最终视图不编辑，以及 POSCAR 保存重读。面板实际绘制已查看，原 Move／Copy 及关闭按钮保留可用布局。GUI 检查使用临时合成模型，没有修改用户计算文件。
- 57 项基础测试、31 项 GTK 小程序启动通过。Python/差异检查通过。未重跑完整 GTK 既有失败套件；未验证 macOS、Windows 新功能和全部手动工作流。

### 使用与交付边界

- 无需打开 Move 面板即可使用方向键；修改步长时才需要打开面板。先让结构窗口获得键盘焦点，使用不带修饰键的方向键。
- 当前已运行的旧进程需要重启。其他设备需先重新编译原生扩展；共享代码不等于已安装新原生模块。
- Windows 打包沿用用户此前的暂缓要求，未恢复构建，现有便携 EXE 不含本次功能。

- Native requests snapshot camera direction and unique base-atom indices. Python edits the owning initial/Build structure only; final/trajectory/primitive/STM views remain non-editing. Coordinate representation, cell/scaling, selective flags, selection and camera are preserved.
- Passed movement unit tests, extended native event/selection regression, actual GTK control/source-save checks, 57 basic tests and 31 applet startups on Linux with synthetic models. Rebuilt native extension/bindings locally; other platforms and full manual workflows are not established. Windows packaging remains deferred.
