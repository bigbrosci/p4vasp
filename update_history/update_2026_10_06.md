# p4vasp fixes — 2026-10-06

## English

### Copied atoms default to T T T

- Changed **Edit → Move atoms → Copy** so newly copied atoms use `T T T` when the current structure has selective dynamics enabled. Previously, new atoms received `F F F` and were fixed during relaxation.
- Existing atoms retain their selective-dynamics flags. The entered translation vector and species grouping are preserved. Structures without selective dynamics remain without selective dynamics.
- The change is in `lib/p4vasp/applet/MoveApplet.py` and applies to copies created after loading the updated application.

### Verification

- Bundled test suite: **57 tests passed**.
- A focused check exercised the copy handler with multiple species and verified translated positions, unchanged original flags, and `T T T` flags after writing and rereading the POSCAR. Structures without selective dynamics were also checked.
- `git diff --check` passed.
- The GTK3 regression suite skipped all seven tests because a display was unavailable. The Move atoms applet startup check could not run because GTK could not connect to the display. The displayed interface was not inspected.

### Update notes organization

- Created `update_history/` and moved all root-level `update_*.md` files, including this note, into it.

## 中文

### 复制的原子默认使用 T T T

- 修改 **Edit → Move atoms → Copy**：当当前结构启用选择性动力学时，新复制的原子默认使用 `T T T`。此前新增原子使用 `F F F`，在结构弛豫时会被固定。
- 原有原子的选择性动力学标记保持不变，输入的平移向量和元素分组顺序保持不变。未启用选择性动力学的结构仍保持原来的模式。
- 修改位于 `lib/p4vasp/applet/MoveApplet.py`，重新启动更新后的程序后，新复制的原子将采用这一默认设置。

### 验证结果

- 内置测试套件：**57 个测试通过**。
- 专项检查调用了复制处理函数，覆盖多个元素的复制，并验证平移后的坐标、原有原子标记不变，以及保存并重新读取 POSCAR 后新增原子的标记为 `T T T`。同时检查了未启用选择性动力学的结构。
- `git diff --check` 通过。
- 由于显示连接不可用，GTK3 回归测试的 7 个测试全部跳过；Move atoms 小程序启动检查也因 GTK 无法连接显示而未能运行。未检查实际界面显示。
