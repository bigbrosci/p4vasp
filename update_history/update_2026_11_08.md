# p4vasp update — 2026-11-08

## English

### Smoother native Show rendering and fine cell outlines

- Changed the native cell default from 2 to 1 pixel, shared with the frequency preview via `viewer_style.CELL_LINE_WIDTH`; new/reopened StructureWindow drawers use this setting. Show retains the shared covalent sphere sizes/colors and original editing controls.
- Native FLTK windows request a multisample visual when available and fall back to RGB/double/depth otherwise. The navigator enables/disables line smoothing and multisampling with its antialias toggle. Softer ambient/diffuse/specular lighting, reduced shininess and an upper-left light reduce harsh highlights and dark hemispheres. Other windows sharing this navigator also inherit the lighting.
- Cell strokes use scoped alpha blending and temporarily disable multisampling for reliable line coverage on the tested driver, restoring GL state before opaque atoms/bonds. Cairo and native OpenGL remain separate renderers; this aligns appearance without claiming pixel identity.

### Verification and limits

- Linux native rebuild passed. Actual OpenGL probe: Mesa 4.5 compatibility, llvmpipe, 4 samples and one sample buffer. Initial multisample-plus-line-smoothing produced no intermediate edge gray; the independent alpha-stroke path produced 45 gray levels. Before/after native captures were inspected. A float line-width argument initially failed the integer native setter; corrected to integer and reran the checks successfully.
- New `testShowQuality.py` passed smoothing off/on pixel coverage (0/45 gray levels), unchanged coordinates/camera/bond state and reopened width 1. Actual Show import/update, centering/replicas/reopening, Delete/Builder/flags and C++ box-selection/hidden/depth/replica/Esc/Side/Space/rotation regressions passed.
- Actual frequency GTK integration, 8 GTK tests, 33 applet startups (GLUT excluded), 57 base tests, Python compilation and diff checks passed. Synthetic data only; R25 was not read or modified. No other GPU/macOS/Windows acceptance or new EXE build. Target machines must rebuild the extension; this Linux installation only needs restarting. Guides and memory updated; unrelated user deletions/calculation directories excluded.

### Show原生显示平滑与细晶胞线

- 晶胞默认线宽2→1像素，与频率预览共用viewer_style.CELL_LINE_WIDTH；StructureWindow创建/重开都使用细线。已统一的共价球半径/颜色及原建模操作保留。
- 原生FLTK窗口优先申请可用MSAA visual，无支持则回退原RGB/双缓冲/深度模式；导航器抗锯齿开关同步控制线平滑和MSAA。调柔环境/漫反射/高光、降低shininess、使用左上光源，减少尖锐亮点和过黑暗面；共享该导航器的其他原生预览也采用此光照。
