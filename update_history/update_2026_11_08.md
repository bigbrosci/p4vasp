## English

### Smoother native Show rendering and fine cell outlines

- Changed the native cell default from 2 to 1 pixel, shared with the frequency preview via `viewer_style.CELL_LINE_WIDTH`; new/reopened StructureWindow drawers use this setting. Show retains the shared covalent sphere sizes/colors and original editing controls.
- Native FLTK windows request a multisample visual when available and fall back to RGB/double/depth otherwise. The navigator enables/disables line smoothing and multisampling with its antialias toggle. Softer ambient/diffuse/specular lighting, reduced shininess and an upper-left light reduce harsh highlights and dark hemispheres. Other windows sharing this navigator also inherit the lighting.
- Cell strokes use scoped alpha blending and temporarily disable multisampling for reliable line coverage on the tested driver, restoring GL state before opaque atoms/bonds. Cairo and native OpenGL remain separate renderers; this aligns appearance without claiming pixel identity.
