# p4vasp fixes — 2026-09-05

This update records the bugs investigated and fixed during this session.

## Fixed issues

- Cell Replication sliders now accept only integer values from 1 through 10, with an increment of 1 and no decimal display.
- Replication values are converted to integers and the structure viewer redraws immediately after changing them.
- GTK3 compatibility now supports legacy selection constants such as `gtk.SELECTION_MULTIPLE`.
- GTK adjustments use `get_value()` and `set_value()` instead of the removed PyGTK `.value` attribute.
- Toolbar applet callbacks were corrected so Show, Control, Build, DOS+bands, STM, and Commit can be switched reliably.
- Repeated applet panel removal and destruction no longer raises `ValueError: list.remove(x): x not in list`.
- Python 2 `md5` and `sha` imports were replaced with Python 3 `hashlib` support.
- Open-file paths now handle GTK `file:` URIs, absolute paths, empty selections, and nonexistent selections.
- Recursive property error handling was fixed so the original loading error is preserved.
- File chooser OK and Cancel handling was corrected.
- Save dialogs now use Save mode and provide a filename field with `POSCAR` as the default name.
- The Build applet no longer displays a large blank text-editor area when the table editor is active.

## Verification

- Modified Python files compile successfully.
- Bundled test suite: **51 tests passed**.

## Launch command

Use the checkout directly so the updated source and GTK compatibility layer are loaded:

```bash
pkill -f p4v.py
cd /home/qli/p4vasp
PYTHONPATH="$PWD/lib:$PWD/src" P4VASP_HOME="$PWD" /usr/bin/python3 p4v.py
```

# p4vasp 修复记录 — 2026-09-05

以下是本次会话中排查并修复的问题。

## 已修复的问题

- Cell Replication（晶胞复制）三个滑块现在只接受 1 到 10 的整数，步长为 1，并且不再显示小数。
- 复制数会在应用前转换为整数，修改复制数后结构查看器会立即刷新。
- GTK3 兼容层增加了旧版 GTK 常量，例如 `gtk.SELECTION_MULTIPLE`。
- GTK Adjustment 改用 `get_value()` 和 `set_value()`，不再使用已经被移除的 PyGTK `.value` 属性。
- 修复了工具栏小程序按钮的回调，使 Show、Control、Build、DOS+bands、STM 和 Commit 可以正常切换。
- 重复移除小程序面板或销毁小程序时，不再出现 `ValueError: list.remove(x): x not in list`。
- 将 Python 2 的 `md5` 和 `sha` 导入替换为 Python 3 的 `hashlib`。
- 打开文件时支持 GTK 返回的 `file:` URI，并统一转换为绝对路径，同时检查空路径和不存在的路径。
- 修复了递归属性错误处理，使真正的文件读取错误不会被 `RecursionError` 覆盖。
- 修复了文件选择器的 OK 和 Cancel 按钮处理。
- 保存对话框现在使用 Save 模式，并提供文件名输入框，默认文件名为 `POSCAR`。
- 修复了 Build 小程序的布局问题：表格编辑器启用时不再出现大面积空白文本编辑区域。

## 验证结果

- 修改后的 Python 文件均可成功编译。
- 内置测试套件：**51 个测试全部通过**。
