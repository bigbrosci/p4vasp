# p4vasp 界面操作指南

适用范围：本项目 `p4vasp-py3` 分支，截至 2026-10-17 的界面与交互。其他版本的按钮和快捷键可能不同。本文根据当前代码和更新记录整理，未在本次编写过程中重新执行全部 GUI 操作。

## 1. 启动与认识窗口

从当前项目目录启动：

```bash
cd ~/opt/p4vasp
PYTHONPATH="$PWD/lib:$PWD/src" P4VASP_HOME="$PWD" /usr/bin/python3 p4v.py
```

在 WSL 中运行时，需要可用的图形显示连接。程序包含两个常用窗口：

- **主窗口**：包含 Open、Show、Control、Build、INCAR 等按钮，用于打开文件、设置显示、编辑结构和生成输入文件。
- **模型窗口**：独立显示三维原子结构，鼠标旋转、Space 和 Shift 框选在这里操作。使用键盘快捷键前，先让模型窗口获得焦点。

更新 Python 界面代码后需要重启程序。涉及 C++ 结构显示功能时，需要先重新编译原生扩展；仅重新启动不会自动编译。

### WSL 结构窗口鼠标大小（2026-10-29 补充）

主窗口采用 GTK，结构窗口采用 FLTK/X11。WSL 中启动三维窗口前，程序会把 GTK 光标主题和尺寸
传给本进程的原生后端；若 GTK 未提供尺寸，使用 24。已有 `XCURSOR_SIZE`、`XCURSOR_THEME` 环境设置保留。
Linux 结构窗口在显示或鼠标进入时明确使用普通箭头，不修改系统光标配置或个人配置文件。

本次包含原生代码调整，更新后需要重新编译并重启。当前维护设备已重编译；其他 Linux 副本可用
`bash install.sh --build-only` 后再 `bash p4v.sh`。WSLg 最终合成的物理光标大小仍需实际显示确认；
不能仅凭 X11 报告的像素尺寸认定视觉问题已经解决。

## 2. 主界面常用入口

| 入口 | 用途 |
| --- | --- |
| Open / File → Load system | 打开结构或计算结果 |
| Show | 显示结构及相关结构信息 |
| Control | 调整模型视角、显示复制、球半径等 |
| Build / Edit → Builder | 编辑晶格、原子坐标和选择性动力学标记 |
| INCAR / Edit → INCAR generator | 按预设和自定义参数生成 INCAR |
| DOS+bands | 查看态密度和能带；需要相应计算数据 |
| STM | 查看相关电荷密度／STM 数据；需要相应输入 |
| Models | 单原子／气相建模及 p4vasp data 元素资料 |
| Database → Resources | 在线数据库导航和 Useful tools |
| File → Save system as | 保存当前系统的初始／Build 结构等内容 |

顶部 **System** 用于识别／切换当前系统。打开多个结构时，编辑和保存前先核对当前系统。

左侧工具栏已经移除了 New 快捷按钮；新建功能仍在 **Edit → New**。

## 3. 打开结构

1. 点击 **Open**。
2. 进入文件所在目录，选择 POSCAR、CONTCAR 或需要读取的计算结果文件，例如 `vasprun.xml`。
3. 确认后查看顶部 System，核对打开的是目标系统。
4. 点击 **Show** 显示三维结构；新窗口会按可见原子范围自动居中并适配大小，通过 **Control** 调整显示。

只有 POSCAR 时，通常只有结构信息，不会因此获得 DOS、能带或完整轨迹。较大的计算结果可能需要解析时间。

## 4. 调整视角与显示

以下鼠标操作在独立模型窗口内进行：

| 操作 | 结果 |
| --- | --- |
| 左键拖动 | 旋转结构 |
| Ctrl + 左键拖动 | 绕垂直于屏幕的轴旋转 |
| 中键拖动 | 平移视图 |
| 右键拖动 | 缩放视图 |
| Shift + 左键拖动 | 框选并反转框内原子的选择状态 |

在 Control 中可以使用 **Top、Side** 等预设视角。Side 对应沿 x 方向观察的侧视方向，选层前应结合实际晶胞朝向确认显示结果。

- **Sphere size**：改变显示球半径，不改变原子的坐标。
- **Cell replication**：显示周期复制，用于观察相邻晶胞；这不等于已经生成并保存了一个含更多原子的超胞。
- 初始、最终或轨迹步结构选项：用于切换查看的结构。查看某一帧不代表 File → Save system as 自动改为保存该帧。

## 5. 选择与取消选择原子

### 单原子：光标 + Space

将光标放到原子上，按 **Space**：未选中的原子变为选中，已选中的原子取消。选中原子周围会出现标记。

### 区域：Shift + 左键拖动

1. 先用 Side、Top 或手动旋转调整到容易区分目标区域的角度。
2. 按住 **Shift**，按住鼠标左键拖出矩形。
3. 松开鼠标，反转矩形内各原子的选择状态。

具体规则：

- 框内未选中的原子 → 选中。
- 框内已选中的原子 → 取消选中。
- 框外原子 → 保持原状态。
- 框内既有已选又有未选原子时，逐个反转，并非统一设为选中。
- 以原子中心在屏幕上的投影判断是否入框，包括后方被遮挡的原子；主动隐藏的原子不参与框选。
- 重复框同一区域会切换回来。想把新区域加入现有选择时，注意避免与已选区域重叠。

### Esc 的两种含义

| 当前状态 | 按 Esc 后 |
| --- | --- |
| 正在拖动矩形 | 取消本次框选，保留拖动前的选择 |
| 没有拖动 | 清空全部原子选择，模型窗口保持打开 |

主界面 Selection 旁的 **0** 也用于清空选择。拖动中窗口失去焦点或改变大小，会取消本次框选。

### 文本选择

Selection 支持原子序号、范围或元素名称，例如：

| 表达式 | 含义 |
| --- | --- |
| `all` | 全部原子 |
| `1 3 5` | 第 1、3、5 个原子 |
| `1-10` | 第 1 至第 10 个原子 |
| `Cu` | Cu 原子，需要结构中有正确的元素信息 |

界面序号从 1 开始。Control 中的 **Put** 将选择表达式应用到模型，**Get** 将模型中的选择读回输入框。主界面 Selection 与不同面板的局部输入框不要混淆。

## 6. Build：编辑结构

### table 表格模式

- **direct**：分数坐标，以晶格矢量为基底。
- **cartesian**：笛卡尔坐标。
- 晶格输入区显示三个晶格矢量；修改数值后按 Enter 提交。
- 原子表格可编辑坐标，编辑完成后按 Enter 提交并核对模型。
- 切换坐标模式会转换表示，避免把分数坐标数值直接当作笛卡尔坐标填写。

### text 文本模式

点击 **text** 可查看／编辑 POSCAR 格式文本，点击 **table** 回到表格。

文本内容涉及标题、缩放、晶格、元素、原子数、坐标模式、坐标及可选的选择性动力学标记。当前文本编辑有尚未解决的实时解析问题：编辑过程中内容暂时不完整可能触发异常。操作前保留原文件；修改后核对原子数、元素顺序、晶格和坐标。

### Selective dynamics：设置运动自由度

开启 **Selective dynamics** 后，表格显示 SX、SY、SZ 等标记。勾选对应允许该自由度（T），不勾选对应固定（F）；其实际方向含义按 VASP 的选择性动力学规则理解，不要只凭 SX/SY/SZ 标签判断为屏幕方向。

这里有一组容易混淆的按钮：

| Build 按钮 | 当前作用 |
| --- | --- |
| Select | 将当前选中原子的三个选择性动力学标记设为 T T T |
| Unselect | 将当前选中原子的三个标记设为 F F F |
| Remove | 删除当前选择的原子 |

**Build 的 Unselect 不是清空鼠标选择。** 想清空选择，用模型窗口中的 Esc 或主界面的 0。

其他常用操作：

- **New Specie**：新增元素分组。
- **New Atom**：向指定分组增加原子，之后检查其元素和坐标。
- **To unit cell / Centered unit cell**：调整原子在周期晶胞中的表示。
- **Remove duplicate**：清理重复原子；执行前保存副本，执行后核对原子数。

## 7. 移动和复制原子

打开 **Edit → Move atoms**：

1. 在 Group 中核对目标原子，必要时用该面板的 Get 读取当前选择。
2. 在 Vector 中填写平移向量三个分量。当前实现按笛卡尔坐标进行平移，不是分数坐标位移。
3. **Move** 移动目标原子；**Copy** 保留原原子，并生成平移后的副本。
4. 在 Build 中核对坐标、元素和原子总数。

如果结构已启用选择性动力学，新复制原子默认采用 **T T T**，原有原子的标记保持不变。需要固定新原子时，再单独设置。

### 结构窗口原子统计与 Delete 删除（2026-11-01）

点击 **Show** 打开的结构窗口左下角会显示当前结构的元素计数，例如 `Cu:64, C:10, H:20, O:2`。同元素的多个原子块合并，统计源结构全部原子（包括隐藏的原子），不把显示周期副本重复计入；旋转、缩放、切换结构和编辑后仍在窗口左下角更新，长内容会折行。空结构显示 `Atoms:0`。右下角同时显示选中原子的分元素计数，如 `Selected: Cu:1, H:1`；同一原子的多个周期副本只计一次，无选择时为 `Selected:0`。左右统计各占独立区域，较长内容分别折行。

在初始／Build 结构窗口选好原子，直接按 **Delete** 删除选中原子，不弹确认框。选择同一原子的多个周期副本只删除原结构原子一次，删除后清空选择并刷新关联面板。无选择或带 Ctrl／Alt／Shift 等修饰键时不执行该快捷删除；最终结构、轨迹、原胞、STM 和气相预览保持只读。

Build 原有删除按钮保持不变。键盘删除保留晶胞、坐标模式／比例和剩余原子的选择性动力学标记；改变的是内存中的初始结构，需按原保存流程保存 POSCAR。连续排队的旧原子数快照不会再次误删其他原子。

本功能修改原生窗口代码，当前 Linux checkout 已重新编译，重启后使用；其他源码副本更新后需要重新编译，不能只同步 Python 文件。

### 按当前视角用方向键移动（2026-10-31 新增）

原来的向量 Move／Copy 操作继续保留。还可以直接在模型窗口操作：

1. 显示初始／Build 结构，选中要移动的原子。
2. 用鼠标把模型转到合适角度，让模型窗口获得键盘焦点。
3. 按 **←／→** 沿屏幕水平移动，按 **↑／↓** 沿屏幕竖直移动。旋转视角后，移动方向随当前相机改变。

无需先打开 Move 面板。默认每次 **0.1 Å**，按实际长度计算，不随缩放改变。
需要调整时，打开 **Edit → Move atoms**，修改 **Arrow-key step (Å)**；该步长在本次程序会话中共享，
不会改变原来的 Vector。普通方向键用于平移，Shift 组合用于下述旋转；其他修饰键组合及拖动模型时不触发编辑。

选中同一原子的多个周期副本时，原胞原子只移动一次，显示副本一起更新。移动保留坐标表示、晶胞、
比例因子和原有选择性动力学标记；修改写回该窗口所属系统的初始结构，可在 Build 核对并通过原保存流程保存。
最终结构、轨迹、原胞及 STM 视图不执行此编辑，需先切回初始结构。模型相机和原子选择保持不变。

本次包含原生代码和绑定更新，其他 checkout 需重新编译后重启；本机 Linux 已重编译。
Windows 打包仍按此前要求暂停，已有便携 EXE 不自动获得此功能。

### Shift＋方向键：绕所选原子质心旋转（2026-10-31）

选中原子并调整观察角度后，在模型窗口按 **Shift＋方向键**，每次旋转 **5°**：

| 快捷键 | 当前视角下的旋转轴与角度 |
| --- | --- |
| Shift＋↑ | 穿过质心、平行屏幕水平 X 轴，−5° |
| Shift＋↓ | 同一 X 轴，＋5° |
| Shift＋← | 穿过质心、平行屏幕竖直 Y 轴，−5° |
| Shift＋→ | 同一 Y 轴，＋5° |

角度采用右手规则，轴随观察角度变化；不是固定晶格轴。原 Rotate atoms 面板的旋转约定不变。
每次按键重新按原子质量计算质心（质量加权，非几何中心），状态栏显示本次质心坐标，单位 Å。
优先用结构中的有效质量，缺失时查项目元素表；质量不可用时提示并保留原结构，不用等质量假设代替。

所选原子刚体旋转，质心和内部距离保持不变，未选原子不动。单个原子绕自身质心旋转时位置不变。
沿用初始／Build 结构限定、原坐标和选择性动力学标记保留，以及相机不动的规则。
重复选中的周期副本按原胞编号去重；质心使用原胞当前坐标，不自动按周期最短距离重构跨边界分子。
角度固定为 5°，Move 面板的 Arrow-key step 只调整普通方向键的平移距离。

## 8. 旋转操作：选择旋转轴与旋转中心

### 先区分：转动视角，还是改变原子坐标

- **仅换一个观察方向**：在模型窗口左键拖动，或使用 Top、Side 等按钮。这不会改变 POSCAR 中的原子坐标。
- **实际转动分子或某组原子**：打开 **Edit → Rotate atoms**。该功能修改初始／Build 结构中指定原子的坐标，保存后会体现在 POSCAR 中；晶格矢量不会随之一起旋转。

因此，想绕指定的 X、Y、Z、晶格方向或某根键旋转原子时，应使用 Rotate atoms，而不是鼠标拖动视图。

### 面板各项的含义

| 控件 | 含义与用法 |
| --- | --- |
| Rotate group | 实际要旋转的原子，例如 `1-12`；只修改这个列表中的原子 |
| Get group | 将当前模型选择写入 Rotate group，同时把 Center 设为该选择中的第一个原子位置 |
| Center | 旋转轴经过的一点，填写三个笛卡尔坐标分量 |
| Second point | 旋转轴上的另一点，用于通过两点计算方向 |
| Axis | 实际使用的旋转轴方向向量，三个笛卡尔分量；不要求长度为 1，但不能为零向量 |
| X / Y / Z | 将 Axis 设为 `(1,0,0)`、`(0,1,0)` 或 `(0,0,1)` |
| a1 / a2 / a3 | 将 Axis 设为当前结构对应的晶格矢量方向 |
| Angle | 旋转角度，单位为度，例如 `30`、`90`、`-30` |
| Rotate | 按当前参数执行一次旋转 |

**旋转轴是一条“通过 Center、沿 Axis 方向”的直线。** 只点 Z 并不意味着一定绕全局原点的 Z 轴：如果 Center 是某个原子的位置，就绕经过该原子、平行于 Z 的直线旋转。

### 方法一：绕 X、Y、Z 或晶格方向旋转

1. 选中需要旋转的原子，打开 **Edit → Rotate atoms**。
2. 点击 **Get group**，核对 Rotate group 的原子列表。
3. 设置 **Center**：可以填写坐标，也可以使用 Center 行的辅助按钮。
4. 最后点击 **X、Y、Z** 或 **a1、a2、a3** 设置方向，检查 Axis 的三个分量。
5. 填写 Angle，然后点击 **Rotate** 一次。
6. 在模型和 Build 中核对位置，再保存结构。

X/Y/Z 是笛卡尔坐标轴，a1/a2/a3 是晶格方向；在斜晶胞中它们一般不重合。它们都不是屏幕的水平／竖直方向，转动观察视角不会改变其物理方向。

建议先设置 Center，再点方向按钮：编辑 Center 或 Second point 并按 Enter，会按“两点之差”重新计算 Axis，可能覆盖之前选好的 X/Y/Z 方向。

### 旋转中心怎样选

Center 行的按钮依据 **Rotate group 中的原子列表**计算：

- **1st**：列表中第一个原子的位置，适合固定某个连接点。
- **last**：列表中最后一个原子的位置。
- **AVG**：所列原子坐标的算术平均值，即几何中心。
- **CMS**：按质量加权的质心，需要有效的元素／质量信息；无法计算时程序会尝试退回几何中心。

先确保 Rotate group 有有效原子，再用这些按钮。几何中心和质心不一定相同。跨越周期边界的分子还应先检查坐标是否连续，避免平均位置落在意外的位置。

**Get group 会重设 Center，但不会保证同步重算 Axis。** 每次重新 Get group 后，都应重新核对中心和轴方向。

### 方法二：用两个点定义旋转轴，例如绕一根键旋转

设轴上的两点为 A 和 B：

```text
Center       = A
Second point = B
Axis         = B − A
```

例如 A 为 `(2,3,4)`，B 为 `(2,3,6)`，则 Axis 为 `(0,0,2)`，即通过 A、沿正 Z 方向的轴。A 和 B 不能相同。

操作步骤：

1. 将需要旋转的分子／片段写入 **Rotate group**。
2. 从 Build 的笛卡尔坐标中读取 A、B 的位置，分别填写 Center 和 Second point。
3. 在 Center 或 Second point 的输入框中按 Enter，计算 Axis，并核对结果。
4. 输入角度，点击 Rotate。

也可以利用 Second point 行的 **1st、last、AVG、CMS** 从模型当前选择中取点。注意两行按钮的数据来源不同：**Center 行读取 Rotate group，Second point 行读取当前全局选择**。设置好目标分组后，可以重新选择 B 原子并点击 Second point 的 1st；此时不要再点 Get group，否则旋转对象也会被改成 B。

轴上的原子理论上保持原位；框选或输入列表中没有包含的其他原子也不会旋转。程序不会自动沿化学键识别“这一侧的整个分子”，需要自行把目标片段完整列入 Rotate group。

### 角度方向与连续操作

当前实现使用的正角方向与常用的右手正角约定相反。例如：Center 为 `(0,0,0)`，Axis 为正 Z，原子从 `(1,0,0)` 出发，输入 **+90°** 后转到约 `(0,-1,0)`；输入 **−90°** 则转到约 `(0,1,0)`。将 Axis 反向也会反转旋转方向。需要精确定向时，先用小角度检查结果。

**在 Angle 输入框按 Enter 会立即执行旋转。** 不要按 Enter 后又点 Rotate，除非希望再转一次。每次执行都是在当前坐标基础上继续旋转，不是设置一个绝对角度。

输入相反角度可以在中心、轴和目标分组保持不变时反向转回，但不等同于通用撤销功能。复杂编辑前先另存结构副本。

### 示例：让一个分子绕自身中心、平行于 Z 的轴转动 30°

1. 在模型中选中整个分子。
2. 打开 Rotate atoms，点 Get group。
3. 在 Center 行点击 **AVG**，将几何中心作为轴上的点。
4. 点击 **Z**，确认 Axis 是 `(0,0,1)`。
5. 在 Angle 填写 `30`，不按 Enter，再点击 Rotate 一次。
6. 检查分子朝向；若想相反方向，使用负角度。保存为新文件名并核对。

本节依据 `RotateApplet.py` 与 `rotateapplet.glade` 的现有实现编写；此次仅更新说明，未修改旋转功能或重新执行其完整 GUI 测试。

## 9. 测量距离、角度和二面角

使用 Control 中的 **Measure** 入口查看选择原子之间的几何关系。选择顺序会影响测量含义。

- 两个原子：关注距离。
- 三个原子：可查看角度。
- 四个原子：可查看二面角。

需要明确测量顺序时，先清空选择，再用 Space 逐个选择。框选的内部顺序不一定是你希望的测量顺序。

## 10. INCAR 生成与保存

1. 点击 **INCAR**。面板初始不勾选预设。
2. 在 Functional、Correction、Model、System、Tasks 等区域选择所需项目。
3. 查看 **INCAR preview**。
4. 在 **Custom parameters** 中按“一行一个 `TAG = value`”修改参数；自定义值覆盖预设。
5. 点击 **Save INCAR…**，填写 Filename 和 Folder；使用 **Browse…** 选择目录。
6. 已有同名文件时确认是否覆盖。

例如：

```text
ENCUT = 520
ISPIN = 2
MAGMOM = 4*5.0 8*0.0
```

上述值只是输入格式示例，应按实际结构和计算目的设置，MAGMOM 的原子数和顺序必须与结构对应。

- **Refresh 会清空预设选择、标准区选择和自定义参数**，不是仅刷新预览。
- MAGMOM 是独立选项，选中 ISPIN 不会自动选中 MAGMOM。
- 预设和元素默认值配置位于 `data/incar/presets.json`；修改后重新打开面板加载。
- **当前代码自动生成 MAGMOM 时仍把各元素分组磁矩设为零**。如需其他初始磁矩，显式填写 Custom parameters。不要仅凭面板中关于 presets.json 的简短提示判断实际磁矩。
- DFT+U 辅助参数依据初始／Build 结构的元素信息及配置生成，保存前检查元素顺序和 U/J 参数。
- 生成器负责输出文件，不会启动 VASP 计算。

## 11. 保存 POSCAR：核对目标与保存对象

使用 **File → Save system as**：

1. 确认顶部当前 System 正确。
2. 真正进入目标目录，核对路径，而不只看文件名输入框中的 POSCAR。
3. 填写 `POSCAR` 或新的文件名，例如 `POSCAR_edit`。
4. 点击 OK 后，检查目标文件的内容和修改时间；必要时重新打开保存后的文件确认。

当前保存处理写的是系统的 **INITIAL_STRUCTURE（初始／Build 结构）**，并非自动导出模型窗口当前显示的最终结构或某个轨迹帧。

保存处理如果收到目录路径，还可能尝试写入 INCAR、KPOINTS、DESCRIPTION 等系统文件。只保存结构时，应明确指定完整的目标文件路径。

**尚未确认的覆盖问题：** 曾报告保存到另一个已有 POSCAR 的目录时，文件看似没有覆盖。临时文件测试能够正常覆盖，尚未复现用户的实际失败路径，因此不能认定已修好或已经找到原因。当前写入错误可能关闭对话框，并提示检查已禁用的日志文件。重要编辑可先另存为新文件名并核对；再次出现问题时，记录目标完整路径、点击过程、提示和文件前后内容。

INCAR 专用保存窗口的覆盖确认，不代表 POSCAR 的 Save system as 使用相同的保存逻辑。

## 12. 示例：选中并固定底层原子

1. Open 打开结构，Show 显示模型。
2. Control 切换到 Side，调整缩放与角度，使层间关系清楚。
3. 在模型窗口按 Esc 清空原有选择。
4. Shift + 左键框住底层原子；观察选中标记。
5. 多选或少选时，用 Space 修正单个原子；也可再次框选一个区域来反转该区域。
6. 打开 Build，启用 Selective dynamics，对当前选中的底层原子点击 **Unselect**，设置为 F F F。
7. 检查其他原子的标记是否符合预期；不要假定它们已自动全部设为 T。
8. 另存为 `POSCAR_fixed`，重新打开并核对标记后再用于计算。

## 13. 常见误区速查

| 现象／疑问 | 应检查的内容 |
| --- | --- |
| 第二次框选后原子反而不选了 | 这是切换逻辑，重复入框会反转状态 |
| 后面的原子也被选中 | 框选按屏幕投影判断，包含遮挡原子；先调整视角 |
| 想清空选择却固定了原子 | Build 的 Unselect 设置 F F F；清空用 Esc 或 0 |
| 看到了多份晶胞，保存后原子数未增加 | Cell replication 是显示复制，不是构建超胞 |
| 保存的结构不是当前显示的那一帧 | Save system as 保存 INITIAL_STRUCTURE |
| 点 Refresh 后自定义 INCAR 参数没了 | Refresh 的设计就是清空并重置 |
| 找不到新生成的 p4vasp.log | 自动文件日志已经禁用；先查看界面和启动终端信息 |
| 更新后快捷键仍旧不对 | 确认原生扩展已编译，并完全重启当前 checkout 的程序 |

相关资料：[更新记录](../update_history/)、[维护记忆](../memory.md)、[GTK3 架构与验证说明](GTK3-migration.md)、[INCAR 生成器说明](../data/incar/README.md)。旧文档与当前实现不一致时，以当前代码和较新的更新记录为准。

## 按当前模型视角导出透明图片

在结构窗口用鼠标调整角度、缩放和位置后，打开 **Control** 面板，点击相机图标 **Export PNG**。导出面板提供预览、模型、材质、图片宽度、质量和亮度；默认哑光、透明背景。

点击 **Export PNG…** 选择保存位置即可。无需再选择 Top/Side 或填写旋转角度；导出读取当前窗口的旋转、平移和缩放，并保持窗口宽高比。打开面板后若继续调整视角，可用 **Refresh preview** 刷新；保存始终使用最新视角。

当前显示的结构帧、隐藏原子和晶胞复制会被保留；箭头、等值面和选中标记暂不导出。图片默认采用 studio 表面光照和逐像素深度渲染，并非窗口截图。交互建模继续采用轻量显示，只有预览/导出才调用精细渲染；预览降低分辨率和采样，保存使用所选质量。详见 [导出指南](render-cli.md)。

### 保存当前角度的复现命令

导出面板默认勾选 **Save reusable command, view preset and structure snapshot**。图片保存后，点击 **Copy command**，下次可在终端直接运行，复现同一视角和渲染设置，无需重新打开 GUI。

PNG 旁会保存 `.POSCAR` 几何快照、`.view.json` 配置和 `command_for_图片名.sh` 命令脚本。批量导出时替换命令中的输入结构和输出图片，保留 `--preset` 配置。其他结构应使用一致的坐标方向与位置；隐藏原子通过编号重放，需要相同的原子顺序。取消勾选可只保存图片。详见 [批量导出指南](render-cli.md)。

### 初始居中与 Home

新建或重新打开结构窗口、切换到新的数据系统时，按可见原子球体的范围自动居中并缩放，保留少量边距。晶胞真空层不参与确定原子模型中心；原子坐标不变。

Top/Side 等视图与缩放围绕模型中心进行。手动旋转后，普通结构刷新或轨迹换帧不会自动重置相机；需要重新居中适配时，点击 Control 的 **Home**。Home 同时恢复默认朝向。

本次包含原生接口更新。此电脑已重编译；其他电脑更新代码后需运行 `bash install.sh --build-only` 并重启。

## 数据库导航与内部资料编辑

左侧 **Models** 打开模型与元素资料；顶部菜单 **Database → Resources** 打开资源导航。两页均隐藏顶部 System／Selection，切回 Build 等结构编辑面板恢复。
**Databases** 提供确认的 16 个网站，按四列四行排列，点击后在网格下方显示网址并自动复制到剪贴板，用户可粘贴到浏览器；剪贴板不可用时选中网址按 Ctrl+C 手动复制。悬停查看用途与网址；卡片只显示数据库名称，不重复显示缩写。
**p4vasp data** 位于 Models 最右侧，显示 H 到 Og 的 118 个元素，按原子序数排序。单位直接写入列标题：Name、atomic number、mass (u)、radii (Å)、R (0–255)、G (0–255)、B (0–255)、Magmom (μB)、U (eV)、J (eV)。前两列只读；双击其他数值编辑，按 Enter，再点 Save，小窗口可双向滚动。

补充数据参考 ASE 3.29.0：质量、范德华显示半径、Jmol 颜色及共价半径；已有 36 元素设置原值保留。目前质量 118 项、显示半径 62 项、颜色 109 套。没有的数据留空，空白不等于零，可自行补填或清空；RGB 为 0–255 整数。radii 为显示半径，共价半径单独保留，不混作同一字段。

元素资料保存到程序的 `data/resources/elements.json`，磁矩／U／J 保存到 `data/incar/presets.json`；原 XML 和数字占位记录保留。保存前校验、备份、检查外部修改，第二文件失败时尝试回滚；Reload 会确认未保存修改。切换 applet 或关闭程序前先保存，修改默认值后重启。更新安装可能覆盖个性修改，应保留备份。

运行时为未知半径／颜色使用绘图回退，但不填回表格；未知质量不能用于质量中心计算。详细来源、同位素质量说明、回退行为、覆盖优先级及恢复方法见 [数据库资料说明](../data/resources/README.md)。修改资料不自动重写当前计算输入。

### 模型库框架

从左侧 **Models** 打开模型库。此页也隐藏 System／Selection，切回编辑面板恢复。顶部横向排列五个标签页，与 Resources 的标签页样式一致：
**single atom**、**gas phase**、**bulk**、**surface**、**p4vasp data**。点击切换，默认打开 single atom；gas phase 为本地分子库，bulk／surface 暂时留空。
Models 独立为左侧按钮，Database 菜单只保留 Resources；元素资料表从 Resources 移到 Models，Commit 快捷入口已移除。

### 单原子输入生成

1. 打开 **Models → single atom**。周期表包含 118 个元素，点击选择，高亮后可点 **Generate inputs**。
2. 弹窗中填写 **Folder name**（新文件夹名称）及 **Save in**（保存的父目录，可 Browse 选择），再点 **Generate inputs**。默认名称为 `Fe_single_atom` 等；可以改名。页面底部不再显示默认 INCAR 参数提示，生成成功后仍显示输出路径。
3. 新目录中生成 `INCAR`、`KPOINTS`、`POSCAR`。同名目录已存在时不会覆盖，需另选名称；取消不生成文件。状态栏显示实际输出路径。

POSCAR 为 13×14×15 Å 正交晶胞，只有所选的一个原子，Direct 坐标 `(0.5, 0.5, 0.5)`，对应笛卡尔 `(6.5, 7, 7.5)` Å。KPOINTS 为 Γ 中心的 `1 1 1` 网格、零偏移。

INCAR 复用当前 **INCAR generator** 的全部 Standard 基础预设，覆盖 `ISPIN=2`、`ALGO=ALL`、`NELM=500`，不输出 `MAGMOM`，不自动套用元素磁矩或 U/J。SYSTEM 标注所选元素；其他参数按当前基础预设保留，不自动启用额外 Task。生成时读取程序 `data/incar/presets.json`，不依赖外部 in.py。界面选择不会修改当前加载的结构、元素资料或 INCAR 预设；这里只生成上述三个文件。

### 气相 XYZ 本地分子库

把单构型 `.xyz` 文件放到仓库的 **`data/models/gas_phase/`**，然后打开 **Models → gas phase**。进入页面会自动扫描，页面已打开时点击 **Refresh**。**Open library folder** 可打开实际目录；页面也显示其完整路径。内置 water、oxygen_triplet 两个格式示例，可复制后修改。

统一格式示例：

```xyz
3
name="Water" charge=0 multiplicity=1 units=angstrom
O   0.000000   0.000000   0.000000
H   0.758602   0.000000   0.504284
H  -0.758602   0.000000   0.504284
```

每个文件只放一个构型，坐标为 Å 单位笛卡尔坐标。电荷／多重度缺失时不猜值，需在界面填写；错误文件显示文件名和行号，不阻止其他文件。盐、多片段、金属配合物均可按此格式提交全部原子坐标，程序不加氢、不重新摆放片段或重建配位。

选择分子后核对 **Charge、Multiplicity、Lx／Ly／Lz**，点击 **Preview 3D** 查看独立三维预览。气相预览采用 0.5 倍共价半径的球棍样式，避免范德华球遮挡；不修改全局元素半径或输出坐标。预览不替换当前加载系统或修改其选择；显示的键只是距离推断，不能代替输入中未保存的配位／键级资料。晶胞默认至少 13×14×15 Å，且每边留至少 6 Å 的包围盒边距，可自行调整。

点击 **Generate inputs**，填写新文件夹名称与父目录，生成 INCAR、Gamma 1×1×1 KPOINTS、按元素分组且整体居中的 POSCAR。保留原子间距离，不改源文件，不覆盖既有目录；源文件几何或元数据已变化时要求刷新后重新确认。

INCAR 以内部 Standard 预设为基础，设置 `ISPIN=2`、`ISMEAR=0`、`SIGMA=0.01`、`NUPDOWN=multiplicity−1`，不设置 MAGMOM；其他基础参数保留。界面只填写 **Charge**（如 -1、+1、0），不再输入 NELECT，也不要求已有 POTCAR。中性体系不写 NELECT；带电 INCAR 写入 `NELECT = SET_AFTER_POTCAR` 和公式注释，保存后需按实际 POTCAR 的 ZVAL 总和减 Charge 补成数值才能运行。Charge=-1 加一个电子，+1 减一个电子；程序不猜电子数。保存弹窗及成功状态均提醒待补全。NUPDOWN 固定自旋电子数差，不保证得到特定自旋本征态／基态。赝势、带电气相有限尺寸修正和收敛性仍需核对，生成文件不等于完成计算。

格式、缺失值、保存及参数细节见 [本地分子库说明](../data/models/gas_phase/README.md)。名称查询尚未加入；SMILES 三维生成见下节。

### SMILES 生成与初步优化

在 gas phase 的 **SMILES** 栏输入例如 `CCO`，点击 **Build 3D + optimize**。生成时补氢，用 ETKDGv3 生成候选、MMFF94s／UFF 初步优化并选已收敛候选中力场能量最低的一份，自动打开三维预览。列表显示 `[SMILES]`；随后继续用 Preview 3D／Generate inputs，输出文件沿用现有气相流程。

Charge 从 SMILES 的形式电荷填入，Multiplicity 留空需确认。结构只是力场初始几何，不是 DFT 结果；盐、多片段及金属等继续导入 XYZ。生成结构只暂存当前页面，离开 Models 前需导出 POSCAR；不会自动写入原 XYZ 库。

本机可选依赖已装入独立 `.venv-smiles`；其他设备需执行 `bash install/install-rdkit.sh`，或设置 P4VASP_SMILES_PYTHON 指向装有 RDKit 的 Python。生成任务可取消、60 秒超时终止，不启动常驻计算进程。完整方法、支持范围、依赖与测试说明见 [SMILES 气相建模](smiles-gas-phase-zh.md)。
