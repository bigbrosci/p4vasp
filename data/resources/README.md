# 数据库导航与内部资料

从工具栏 **Database** 或菜单 **Database → Resources** 打开。此页面隐藏共用的 System／Selection 两行；切回结构编辑面板恢复。

## 在线数据库

16 张卡片按四列四行排列，只显示网站名称。点击后在网格下方显示可选中复制的网址，并自动复制到剪贴板；不自动打开浏览器。剪贴板不可用时可在网址框按 Ctrl+C 手动复制。悬停显示用途和网址，启动不联网获取图标或数据。

网站目录为 `websites.json`。部分服务需注册、订阅或许可证，导航不提供这些权限。数据库菜单中的 Models 以顶部横向四个标签页 single atom、gas phase、bulk、surface 展示空模型库框架，点击切换；左侧工具栏 Commit 保留。

## 元素资料表

**p4vasp data** 显示从 H 到 Og 的 118 个元素，按原子序数排序。列标题直接注明单位：Name、atomic number、mass (u)、radii (Å)、R (0–255)、G (0–255)、B (0–255)、Magmom (μB)、U (eV)、J (eV)。Name 是元素符号，与原子序数只读。双击其他单元格修改，按 Enter，再点 Save；小窗口可双向滚动。

目前包含 118 项质量、62 项显示半径、109 套颜色，以及既有磁矩／U／J 默认值。空白表示未知或未设置，不代表零；可补填或清空单元格。RGB 接受 0–255 整数，保存为内部 0–1，未编辑的通道保留原始精度。质量须为正，半径非负，所有填写数值须有限；磁矩允许负数。radii 是可视化显示半径，并非所有元素都有统一意义的“原子半径”。

程序默认元素资料现为 `data/resources/elements.json`，磁矩／U／J 仍在 `data/incar/presets.json`。原 `data/atomtypes.xml` 保留为历史初始表和数字占位记录来源，其已有 36 个真实元素的质量、半径、共价半径和颜色在补全时原值迁入新资料；以后用表格编辑的是新 JSON，不再修改旧 XML。共价半径保留在资料中，但不显示为本表的 radii 列。

## 数据来源与缺失值

补充数据来自 ASE 3.29.0 发布包：质量用 `atomic_masses_iupac2016`；新显示半径用 `vdw_radii`（范德华半径）；新增颜色用 `jmol_colors`（Jmol 配色）；补充共价半径用 `covalent_radii`。已有 36 元素的设置优先保留。质量包含对没有稳定同位素的元素所选同位素质量，不应一概当作天然丰度标准原子量。ASE 的缺失／占位半径被转换为 null，没有作为实测数值填入。

来源说明：[ASE 数据文档](https://ase-lib.org/ase/data.html)、[ASE 官方源码](https://gitlab.com/ase/ase)。归档文件名与 SHA-256 在 JSON 的 source 字段中，[ASE 许可](ASE-LICENSE.txt)随数据保留。维护者可用 `python3 tools/import_element_reference.py /path/to/ase-3.29.0-py3-none-any.whl` 重建补充表；这是按旧 XML 重建默认数据，会覆盖 JSON 个性修改，不应作为普通更新步骤。运行 p4vasp 不需要安装 ASE。

GTK 原生结构显示和图片导出均读取新资料。为让未知资料的元素仍可绘制，运行时对空半径使用 1 Å 的显示回退、空 RGB 通道使用白色分量；空质量为未知，不能据此求质量中心；空共价半径不用于自动判键。这些只是运行时回退，不保存为表格中的科学资料。已有 `~/.p4vasp/atomtypes.xml` 或当前目录元素表依旧可覆盖 GUI 默认值；独立图片导出的原有路径不读取这些个人 XML 覆盖。

## 保存与恢复

Save 校验后直接修改当前程序的 JSON 文件，保存前备份到 `~/.p4vasp/backups/`，再原子替换单个文件。外部源文件变化会拒绝保存；第二个文件写入失败时尝试回滚第一个，回滚也失败会报告恢复路径。多文件写入不是断电安全事务。权限不足会报错，不自动提权、不改为用户覆盖文件。

Reload 前有修改会询问；切换 applet 或关闭程序前应先保存。元素和 INCAR 缓存需重启后应用，修改默认资料不会自动重写当前结构或已生成计算输入。更新、重装可能覆盖个性修改，请保留备份并核对后迁移。恢复时复制备份到对应程序 JSON 路径，再重启。
