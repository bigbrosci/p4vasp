# 本地气相分子库

把 XYZ 文件放入本目录，在 **Database → Models → gas phase** 中选择。进入该标签页会自动扫描；已打开时点击 **Refresh**。支持 `.xyz`／`.XYZ`，每个文件只允许一个构型。**Open library folder** 打开实际使用的目录，路径也显示在页面中。只扫描当前目录，不递归、不后台运行外部程序。

建议文件名仅使用英文、数字、下划线，例如 `complex_001.xyz`、`ethanol_conf01.xyz`；异构体／构象分别保存。文件用 UTF-8，第一行原子数，第二行注释，之后恰好对应数量的原子坐标：

```xyz
3
name="Water" charge=0 multiplicity=1 units=angstrom
O   0.000000   0.000000   0.000000
H   0.758602   0.000000   0.504284
H  -0.758602   0.000000   0.504284
```

- `name`：显示名称，有空格时加双引号；键值注释未提供 name 时使用文件名；普通自由注释作为显示名称。
- `charge`：整个体系的整数总电荷，正号表示失去电子。
- `multiplicity`：整数自旋多重度 `2S+1`，至少为 1。
- `units`：固定为 `angstrom`。省略时按普通 XYZ 的 Å 单位处理，其他单位拒绝导入。
- 坐标为 `元素符号 X Y Z`，元素符号按周期表大小写，坐标为有限的笛卡尔数值，不用 Direct 分数坐标或原子序数。

第二行也可保留普通自由注释；这时电荷与多重度显示未指定，生成前必须在界面填写。若使用键值语法，只允许以上四个键；重复或拼写错误会标出文件名与行号。读入失败的文件保留在列表中显示错误，不阻止其他文件。文件中的原子数不匹配、多帧、未知元素、非有限坐标均拒绝。

盐、多片段和配合物的全部原子放在同一文件，保留用户设定的相对位置。程序不加氢、不重构配位、不做力场优化，不移动单独片段。这里提供的 water 和 oxygen_triplet 是格式／初始结构示例，不能视为已完成量化优化。

## 预览与生成

选择文件后检查电荷、多重度及 Lx／Ly／Lz。**Preview 3D** 在独立的原生结构窗口显示预览，不替换当前加载系统，预览选择与关闭不作用于当前系统。显示的键只作距离推断，XYZ 不含明确键级／配位定义。POSCAR 按元素首次出现顺序分组，同时对应重排原子坐标；仅整体平移，将分子包围盒中心放在晶胞中心，保持原子间距离和源文件内容。

晶胞默认每方向至少为 13／14／15 Å，并至少为该方向分子跨度加 12 Å（每边 6 Å），向上取整。可手动调整，但每方向必须大于分子跨度。这个默认尺寸只是起始值，最终真空收敛性由用户检查。

点击 **Generate inputs**，填写新文件夹名称与父目录，生成三个文件：

- `POSCAR`：上述晶胞及居中的原始分子构型。
- `KPOINTS`：Gamma `1 1 1`、零偏移。
- `INCAR`：沿用内部 INCAR generator 的 Standard 基础设置，覆盖 `ISPIN=2`、`ISMEAR=0`、`SIGMA=0.01`、`NUPDOWN=multiplicity-1`；不使用默认 MAGMOM、元素 U/J、SOC／非共线设置。其他基础值保留，并非自动套用 single atom 的 ALGO／NELM 覆盖。

界面只输入 **Charge**（例如 `-1`、`+1`、`0`），不填写 NELECT，也不要求预先有 POTCAR。中性体系不写 NELECT，交给 VASP 按最终 POTCAR 确定。带电体系仍可生成三文件，但 INCAR 是**待补全模板，不能直接运行**：

```text
# NELECT = sum(atom_count * POTCAR ZVAL) - (+1)
# Negative charge adds electrons; positive charge removes electrons.
NELECT = SET_AFTER_POTCAR
```

上例为 Charge=+1，需从中性价电子总数减去 1；Charge=-1 则加 1。拿到实际计算所用的 POTCAR 后，按各元素 ZVAL 与原子数求和再减 Charge，将占位符替换为数值。程序不填猜测数值；不能简单将原子序数相加代替价电子数。还需核对 NELECT 与 NUPDOWN 的数量和奇偶性，当前模板阶段不做此数值检查。保存弹窗与成功状态都会提醒带电模板需补全。

总电荷和多重度记录在 INCAR 注释中；NUPDOWN 约束上下自旋电子数差，不保证目标自旋本征态或基态。参考 [NELECT](https://vasp.at/wiki/NELECT)、[NUPDOWN](https://vasp.at/wiki/NUPDOWN)。周期带电气相体系的有限尺寸／静电修正需自行选择，本功能不自动添加修正。

只创建新目录，不覆盖已有目录；取消不生成文件。生成前检查 XYZ 内容是否已变化，变化时要求 Refresh 后重新确认；写入失败会清理本次已写的文件。生成输入不等于完成 VASP 计算，POTCAR 不在此功能中生成。

## 从 SMILES 新建结构

同一 gas phase 页面可输入 SMILES，点 Build 3D + optimize 补氢、生成三维构象并初步优化，随后复用预览及导出按钮。新结构只暂存内存，不自动改写此目录；需导出后再离开 Models。形式电荷自动填入，自旋多重度需确认；盐、多片段、金属等仍使用本目录的 XYZ 接口。

这是可选 RDKit 功能，安装、优化方法与限制见 [SMILES 建模说明](../../../doc/smiles-gas-phase-zh.md)。
